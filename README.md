# yt-dlp 简易视频下载器

[English](README.en.md)

一个方便日常使用的 Windows 视频下载小工具，基于 yt-dlp 开发，支持自动下载 yt-dlp 并循环下载视频。

---

## 功能特点

- 双击即可运行，无需安装
- 第一次运行会自动下载最新版 `yt-dlp.exe`
- 支持循环输入链接持续下载
- 适合单次下载长视频
- 自动将视频保存到 `source` 文件夹

---

## 使用方法

1. 下载 `video_download.bat` 文件
2. 双击运行
3. 第一次运行会自动下载 `yt-dlp.exe`（约 17MB）
4. 粘贴视频链接后按回车开始下载
5. 下载完成后会自动回到输入界面，可继续粘贴下一个链接
6. 直接按回车或输入 `q` 退出程序
