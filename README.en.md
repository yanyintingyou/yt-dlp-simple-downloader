# Simple yt-dlp Video Downloader

[中文](README.md)

A lightweight Windows video downloader based on yt-dlp. It automatically downloads yt-dlp and supports continuous video downloading in a loop. Ideal for occasional long video downloads.

---

## Features

- Double-click to run, no installation required
- Automatically downloads the latest `yt-dlp.exe` on first run
- Supports loop mode for continuous downloading
- Suitable for single long video downloads
- Automatically saves videos to the `source` folder

---

## How to Use

1. Download `video_download.bat`
2. Double-click to run
3. On first run, it will automatically download `yt-dlp.exe` (about 17MB)
4. Paste video URL and press Enter to start downloading
5. After download completes, it returns to the input prompt for the next link
6. Press Enter or type `q` to exit the program
